# 机场翻 Editorial：杂志式设计框架

最新内容状态：全部240篇文章已逐篇实质修订，29个品牌、58档价格/流量/规格和12个优惠码均已同步。逐篇修改与验收见“博客内容优化说明.md”及项目 docs/full-editorial-review.md；本文件保留结构、来源或优化方法说明。


本次将原来的蓝色资讯门户布局替换为完整的杂志式设计体系。暖白背景、深墨绿主色与少量香槟金作为视觉基调，配合衬线标题、细线分隔、编号目录和更宽松的版面。

本次“框架升级”指视觉体系、布局与页面组件重构。底层技术仍为 Astro、TypeScript、Tailwind 与静态生成，未迁移到 Next.js 等其他技术栈。

## 页面组织

首页按品牌观察、29品牌目录、需求探索、编辑选读、设备教程、横向比较与常见问题展开。主视觉为代码绘制的SVG连接地图，明确标注示意用途，不代表真实线路或覆盖范围。

博客目录改为桌面双栏阅读索引，手机端单栏。文章页采用衬线大标题、宽松行距、独立正文与目录侧栏。品牌资料、套餐、优惠码、推荐专题和比较工具统一使用新版设计样式。

## 主要组件

- `src/styles/editorial.css`：色彩、字级、间距、响应式断点、表格、卡片与阅读排版；替换原global.css。
- `SiteHeader.astro`：吸顶导航、当前页标记、移动菜单与搜索入口。
- `SiteFooter.astro`：杂志式页脚、完整导航和推广披露。
- `SiteMark.astro`：可缩放的几何品牌标识。
- `ConnectionAtlas.astro`：首页连接地图示意。
- `BrandCard.astro`：品牌、来源状态、价格、流量与优惠信息。
- `BlogArchive.astro`：文章目录与分页。
- `Base.astro`：复用页眉页脚，保留SEO元信息和优惠码复制行为。

## 阅读与操作

桌面、平板、手机分别调整布局。表格在自身区域横向滚动；手机导航展开后可浏览全部主入口，Escape关闭菜单并恢复焦点。键盘焦点保留明显边框，系统减少动画偏好会关闭平滑滚动和过渡。

字体使用系统已有字体，没有新增外部字体或追踪请求。地图和标识为SVG；首页分享图片与favicon同时更新。数值使用现有数据库计算，没有增加虚构测速、口碑或性能评分。
