# 五、首页设计（重点）

首页是整个网站最重要的 SEO 落地页。

首页必须以本次指定的 Bing 主攻关键词作为核心主题。

## 5.1 首页布局

按照以下顺序制作：

### Section 1：Header

包含：

- 原创文字 Logo
- 首页
- 机场推荐
- 机场排行
- 机场评测
- 机场对比
- 使用教程
- 博客文章
- 搜索按钮

导航必须简洁。

手机端使用折叠菜单。

### Section 2：Hero

包含：

- 唯一 H1
- 主关键词自然出现
- 直接回答搜索需求的介绍
- 主要专题入口
- 简洁的辅助说明

禁止机械重复关键词。

### Section 3：快速答案

为搜索用户提供立即可用的结论。

例如：

- 新手应该如何选择？
- 哪些因素最值得关注？
- 如何判断套餐是否划算？
- 购买前应该检查什么？

### Section 4：精选推荐

采用专业卡片布局。

每张卡片包含：

- 机场名称
- 简介
- 适合人群
- 起步价格
- 套餐流量
- 线路类型
- 优点
- 注意事项
- 查看详情

不得虚构评分或测试结果。

### Section 5：综合排行榜

展示已核实的机场排名。

包含：

- 排名
- 品牌
- 套餐价格
- 流量
- 线路
- 适合人群
- 详情入口

### Section 6：按需求选择

制作六个专题入口：

- 低预算
- 高端专线
- 新手入门
- 稳定优先
- AI 服务
- 流媒体

### Section 7：机场比较

展示横向比较工具入口。

### Section 8：最新深度评测

展示最新发布的独立评测。

### Section 9：教程中心

展示 Windows、Android、iOS 和 macOS 教程。

### Section 10：知识百科

展示常见专业术语和基础知识。

### Section 11：最新文章

展示最近更新的优质文章。

### Section 12：FAQ

围绕核心关键词建立真实、有用的常见问题。

### Section 13：Footer

包含：

- 网站导航
- 编辑政策
- 关于我们
- 联系方式
- 隐私政策
- 免责声明

# 八、排行榜系统

至少建立以下四种排行榜模板：

1. 综合排行榜
2. 性价比排行榜
3. 低预算排行榜
4. 稳定性排行榜

## 综合榜

根据实际可核验的维度进行评价。

如果没有实测数据，不得使用测速结果参与评分。

评分规则必须公开。

## 性价比榜

支持自动计算：

每 GB 单价 = 套餐价格 / 实际可用流量。

注意：

- 月付与年付必须明确区分。
- 倍率流量必须正确折算。
- 不限时套餐不得直接当作月付套餐。
- 未核实套餐不得参与自动排序。

## 排行榜页面

必须包含：

- 快速结论
- 排名依据
- 比较表格
- 各品牌简介
- 适合人群
- 相关评测
- 更新时间
- 数据来源

# 十三、Bing SEO 技术系统

本阶段为最高优先级之一。

## 13.1 全站 Metadata

每个页面必须具有：

- 独立 Title
- 独立 Meta Description
- 正确 Canonical
- Robots Meta
- Open Graph
- Twitter Card
- 唯一 H1

Title 必须自然。

不能机械地在所有页面重复主关键词。

## 13.2 URL

采用简洁英文 Slug。

统一尾部斜杠策略。

全部正式 URL 必须使用指定域名。

禁止出现：

localhost、测试域名、错误 Canonical。

## 13.3 Sitemap

自动生成：

/sitemap-index.xml

确保：

- 仅包含正式 URL
- 排除草稿
- 排除 404
- 排除 noindex 页面
- 排除重复 URL

lastmod 必须对应实际内容修改时间。

## 13.4 Robots.txt

正确声明 Sitemap。

允许搜索引擎抓取正式公开页面。

不得误封锁 CSS、JS、图片和重要内容。

## 13.5 Schema

实现适用的结构化数据：

- Organization
- WebSite
- BreadcrumbList
- BlogPosting
- Article
- ItemList

所有结构化数据必须与可见页面内容一致。

## 13.6 IndexNow

创建完整 IndexNow 模块。

必须支持：

- API Key 配置
- Key 文件验证
- 单 URL 提交
- 批量 URL 提交
- 新增内容提交
- 更新内容提交
- HTTP 响应日志
- 失败重试

提供命令：

npm run indexnow

禁止每次构建都无差别提交全部 URL。

不得声称 IndexNow 成功就代表 Bing 已收录。

## 13.7 Bing Webmaster Tools

提供完整操作文档：

- 网站验证
- Sitemap 提交
- IndexNow 验证
- URL Inspection
- Search Performance
- Index Coverage
- Crawl Issues

需要人工登录或授权的步骤必须明确说明。
